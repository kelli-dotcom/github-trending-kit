# Contributing

Contributions, new additions, and improvements are welcome!

## How to Contribute
1. Fork the repository.
2. Create a feature branch (`git checkout -b feat/your-addition`).
3. Keep additions modular, well-documented, and 100% original/IP-safe.
4. Open a Pull Request describing what you added and how to test it.

## Not Sure Where to Start?
Open an Issue using our Feature Request template to pitch an idea before writing code.
