# Mistakes & Guardrails (`mistakes.md`)

## Never Repeat
1. **Text-Only READMEs:** Every README MUST include a real integrated visual demonstration (`assets/demo.gif` or `demo/preview.svg`).
2. **Competitor Trademarks:** Never name competitor brands in comparison tables—compare against generic industry categories only.
3. **Vendor-Locked Skills:** Keep every `SKILL.md`, `AGENTS.md`, and `llms.txt` plain standard Markdown so all AI models can execute them cleanly.
