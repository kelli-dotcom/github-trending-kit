# Contributing to GitHub Trending Kit (`CONTRIBUTING.md`)

Thank you for contributing to **GitHub Trending Kit**! Both **human open-source maintainers** and **AI agents** are welcome to contribute README archetypes, conversion templates, and launch skills.

---

## 1. High-Impact Ways to Contribute
- **README Conversion Archetypes (`templates/` & `skills/top-github-readme/SKILL.md`):** Refine above-the-fold layouts for Product Showcases, Developer SDKs, and System Maps.
- **Contribution & Community Templates (`skills/contribution-setup/SKILL.md`):** Improve `CONTRIBUTING.md` blueprints and PR/Issue checklists.
- **Launch Director Playbooks (`agents/launch-director.md`):** Add ethical, high-signal launch checklists and visual demo (`demo.gif` / `preview.svg`) recipes.

## 2. Human & AI Agent Guardrails (`AGENTS.md` + `llms.txt`)
- **Mandatory Integrated Visual Demo:** Every README template or example MUST include an embedded visual demonstration (`assets/demo.gif` or `demo/preview.svg`).
- **IP-Safe Comparisons:** Never name competitor trademarks in comparison tables—compare against generic industry categories only.
- **All-Model Ready:** Keep all `SKILL.md` and `AGENTS.md` files in plain standard Markdown.

## 3. 60-Second Verification Gate (Required Before Every PR)
```bash
ls -la AGENTS.md HANDOFF.md mistakes.md llms.txt skills/top-github-readme/SKILL.md skills/contribution-setup/SKILL.md
```

## 4. 3-Step Pull Request Workflow
1. **Fork & Branch:** `git checkout -b feat/your-readme-or-launch-improvement`
2. **Verify Links & Assets:** Confirm all relative links, badges, and visual demo paths resolve cleanly.
3. **Submit a Pull Request:** Open a PR against `main` with a before/after preview or summary.

## 5. IP Safety & MIT License
All contributions must be original clean-room work and are licensed under the repository's [MIT License](LICENSE).
